# SYSTEMS REBORN

A clean-room Fabric client project targeting Minecraft 1.21.11.

## Status

Project initialization. Gameplay modules and the in-game interface are being implemented incrementally; this repository is not yet a release build.

## Build

The project uses Gradle and Fabric Loom. See the build workflow and Gradle files as they are added.

## Scope

- Minecraft 1.21.11 / Fabric
- Legit-oriented client features and quality-of-life modules
- In-game ClickGUI and HUD
- No KillAura, Hitbox, Reach, or anti-cheat bypass features
